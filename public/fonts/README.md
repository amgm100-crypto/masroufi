# ضع ملفات خط ثمانية هنا

1. حمّل الخط من موقع ثمانية الرسمي (الملفات توصلك على الإيميل).
2. انسخ ملفات OTF إلى هذا المجلد.
3. إذا كانت أسماء الملفات مختلفة عن الموجودة في أعلى `styles.css`، عدّل المسارات هناك (لا تغيّر أسماء الملفات نفسها، لأن الرخصة تمنع ذلك).

الأسماء المتوقعة حاليًا:
- `ThmanyahSans-Regular.otf`
- `ThmanyahSans-Medium.otf`
- `ThmanyahSans-Bold.otf`
- `ThmanyahSerifDisplay-Bold.otf`

إذا كان الخط مثبّتًا على جهازك، تستخدمه المنصة تلقائيًا حتى بدون هذه الملفات.
راجع رخصة الخط قبل نشر الموقع للعامة.
