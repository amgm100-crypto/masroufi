# مصروفي

تطبيق ويب لإدارة المصروف الشخصي. يفصل المصروف الشخصي عن العهد والأمانات، ويتابع الديون والإيرادات، ويستورد كشف الحساب.
يعمل بالكامل داخل المتصفح، وكل البيانات مشفّرة على جهازك. التفاصيل في [SECURITY.md](SECURITY.md).

## أول دخول

| | |
|---|---|
| اسم المستخدم الافتراضي | `masroufi` |
| كلمة المرور الافتراضية | `Masroufi@2026` |

بعد أول دخول تطلب المنصة اسم مستخدم وكلمة مرور جديدة، ولا تفتح قبل تغييرها. بعدها ما تشتغل البيانات الافتراضية.

## الخط

المنصة مصممة على **خط ثمانية**: Thmanyah Sans للنصوص، وThmanyah Serif Display للعناوين والأرقام الكبيرة.
حمّل الخط من موقع ثمانية الرسمي وضع ملفات OTF في مجلد `public/fonts/` (التفاصيل في `public/fonts/README.md`). لو كان الخط مثبّتًا على الجهاز، تستخدمه المنصة تلقائيًا.

## الملفات

| الملف | الوصف |
|---|---|
| `public/index.html` | الصفحة الرئيسية، وفيها سياسة CSP |
| `public/styles.css` | التصميم (فاتح وداكن، ويتكيّف مع الجوال) |
| `public/app.js` | التطبيق كاملًا: التشفير، والحسابات، والواجهة، وقراءة CSV |
| `public/_headers` | رؤوس أمان HTTP لـ Cloudflare Pages وNetlify |
| `render.yaml` | إعداد النشر على Render مع رؤوس الأمان |
| `build/masroufi-preview.html` | نسخة بملف واحد للمعاينة |

## التشغيل على جهازك

التشفير في المتصفح يحتاج `https` أو `localhost`:

```bash
cd masroufi/public
python3 -m http.server 8000
```

ثم افتح http://localhost:8000

## النشر

- **Cloudflare Pages** أو **Netlify** (موصى بهما): ارفع المجلد كما هو، وملف `_headers` يُطبّق تلقائيًا.
- **GitHub Pages**: يعمل، لكن بدون رؤوس `_headers` (سياسة CSP داخل الصفحة تبقى فعّالة).

## حساباتي

قسم «حساباتي» يجمع حساباتك البنكية وبطاقاتك. كل كشف تستورده ينربط بحسابه ويحدّث رصيده تلقائيًا، والتحويلات بين حساباتك وسداد البطاقة ما تنحسب مصروفًا ولا دخلًا.

## استيراد كشف الحساب

ارفع كشف **PDF** من تطبيق الراجحي أو الإنماء مباشرة، أو ملف CSV.
ملف PDF يُقرأ داخل المتصفح بمكتبة [PDF.js](https://mozilla.github.io/pdf.js/) (رخصة Apache 2.0) المحفوظة في `public/vendor/pdfjs`، فما يطلع الكشف من جهازك. الكشوف المحمية بكلمة مرور مدعومة، أما الكشوف الممسوحة ضوئيًا (صور) فما تنقرأ.
يتعرّف التطبيق على أعمدة: التاريخ، والوصف، والمبلغ (أو مدين/دائن)، بالعربي أو الإنجليزي.

## النشر على Render

1. في Render اختر **New ← Blueprint** واربط هذا المستودع.
2. Render يقرأ `render.yaml` وينشئ موقعًا ثابتًا مجانيًا من مجلد `public` مع رؤوس الأمان.
3. كل تعديل يُدفع إلى الفرع `main` يُنشر تلقائيًا.

> ملفات خط ثمانية مستثناة من المستودع (`.gitignore`) لأن رخصتها تمنع إعادة توزيعها. ارفعها بنفسك فقط إذا كانت الرخصة تسمح لك بذلك.
